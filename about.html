広告について

当サイトはアフィリエイト広告を利用しています。 広告を掲載している箇所には「広告」と明示しています。

当サイトのリンクを経由して商品やサービスが購入された場合、当サイトが報酬を得ることがあります。 利用者が支払う金額が、これによって上乗せされることはありません。

広告の掲載ルール（自主的に定めているもの）

  • 広告は、選手の写真や移籍情報のカードとは分離した専用の枠にのみ掲載します。
  • 特定の選手の写真と商品リンクを組み合わせて表示しません。 選手の肖像を商品の広告として使うことはしない、という方針です。
  • 移籍情報の内容や確度スコアが、広告主の意向によって左右されることはありません。
  • 記事の体裁をとった広告（記事広告）は掲載しません。

Cookieの取り扱いについてはプライバシーポリシーをご覧ください。

確度スコア（0〜100%）について

表示している確度は、このサイト独自の推定値です。 公式情報ではなく、予測の的中を保証するものでもありません。

移籍が成立する確率を示す公的な指標は存在しません。当サイトの数字は、 報道の段階とソースの信頼度を次の基準で機械的に組み立てたものです。

1. 交渉段階でベースを決める

段階ベース
クラブが公式発表（＝推定ではなく事実）100%
メディカル実施／発表待ち85〜99%
移籍金でクラブ間が合意70〜85%
個人条件で合意、クラブ間は未合意55〜70%
クラブ間で交渉中／オファー提出35〜55%
打診・代理人接触が報じられた20〜35%
興味・リストアップの報道のみ5〜20%

2. ソースの信頼度で補正

Tier該当補正
1クラブ公式・リーグ公式そのまま採用
2BBC / Sky Sports / Fabrizio Romano / L'Équipe / Bild など一次取材メディア±0
3全国紙・大手スポーツ紙の追随報道−5
4まとめ系・アグリゲーター−15

3. さらに加減算

  • 独立した複数の Tier2 が一致 … +5〜10
  • クラブ／選手側が公式に否定 … −20
  • 報道が5日以上更新されていない … −10
  • 移籍市場の閉幕まで7日未満で未合意 … −10
  • 行き先が複数クラブで競合 … 「移籍する確率 × そのクラブを選ぶ確率」で割り引く

推定値の上限は99%です。まだ噂である限り100%にはなりません。 100%はクラブが公式発表した案件のみで、この場合は「成立」バッジが付き、確度の推定対象から外れます。 各カードの「この確度の根拠」を開くと、どの帯から何を加減算したのかが確認できます。

データの更新

日本時間の16時から翌9時まで、1時間ごとに自動で更新しています。 休止している時間帯は、欧州の報道が動かない深夜〜早朝にあたります。

選手写真の出典とライセンス

選手写真は Wikimedia Commons 上の自由ライセンス画像のみを使用しています（CC BY 4.0 / CC BY-SA 4.0 / CC BY-SA 3.0 / CC BY-SA 2.0 / CC BY 3.0 / CC BY 2.0 / CC0 / パブリックドメイン）。 撮影者名・ライセンス名・Commons のファイルページへのリンクを、各カードの下部に個別に表示しています。

フェアユース画像および出所不明の画像は使用していません。 写真が存在しない選手は、イニシャルのアバターで表示します。

クラブのエンブレム・ロゴは一切使用していません。 これらは著作権および商標の対象であり自由ライセンスではないためです。 クラブの識別はクラブカラーの色チップで行っています。

移籍情報の出典

各カードに出典元の報道機関と記事へのリンクを表示しています。 記事本文は転載しておらず、要旨のみを独自の日本語文にまとめています。 リンク先記事の著作権は各報道機関に帰属します。
