この確度（0–99%）はどう決めているか

公式発表以外に「移籍が成立する確率」の公的な指標は存在しません。ここに出る数字は 報道の段階とソースの信頼度を下の基準で機械的に組み立てた、このサイト独自の推定値です。 予測の的中を保証するものではありません。

1. 交渉段階でベースを決める

  • 100% クラブが公式発表（＝推定ではなく事実）
  • 05–20% 興味・リストアップ段階の報道のみ
  • 20–35% 打診・代理人接触が報じられた
  • 35–55% クラブ間で交渉中／オファー提出
  • 55–70% 個人条件で合意、クラブ間は未合意
  • 70–85% 移籍金でクラブ間合意
  • 85–99% メディカル実施／発表待ち

2. ソースの信頼度で補正

  • Tier 1 クラブ公式・リーグ公式 … そのまま採用
  • Tier 2 BBC / Sky Sports / Fabrizio Romano / L'Équipe / Bild など一次取材メディア … ±0
  • Tier 3 全国紙・大手スポーツ紙の追随報道 … −5
  • Tier 4 まとめ系・アグリゲーター … −15

3. さらに加減算

  • 独立した複数のTier2が一致 … +5〜10
  • クラブ／選手側が公式に否定 … −20
  • 報道が5日以上更新されていない … −10
  • ウィンドウ閉幕まで7日未満で未合意 … −10

推定値の上限は99%です。まだ噂である限り100%にはなりません。 クラブが公式発表した時点で「成立」バッジ付きの100%に切り替わり、確度の推定は役目を終えます。 つまり 100% だけが推定ではなく事実で、99%以下はすべてこのサイトの見立てです。

このサイトについて

個人が趣味で運営している非営利のファンサイトです。広告掲載・課金・物販は一切行っていません。 いかなるクラブ・リーグ・選手・報道機関とも提携しておらず、公式サイトではありません。

確度スコアについて

表示している確度は、報道の段階とソースの信頼度から算出したこのサイト独自の推定値です。 公式情報でも予測の的中を保証するものでもありません。推定値の上限は99%で、 100%はクラブが公式発表した案件のみに使用しています。算出基準は 確度の付け方に全て公開しています。

選手写真の出典とライセンス

選手写真は Wikimedia Commons 上の自由ライセンス画像のみを使用しています（CC BY 4.0 / CC BY-SA 4.0 / CC BY-SA 3.0 / CC BY-SA 2.0 / CC0）。撮影者名・ライセンス名・Commons のファイルページへのリンクを 各カード下部に個別に表示しています。フェアユース画像および出所不明の画像は使用していません。 写真が存在しない選手はイニシャルのアバターで表示します。
